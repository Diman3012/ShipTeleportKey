# ShipTeleportKey

Мод для Lethal Company (BepInEx 5): по нажатию кнопки телепорт корабля забирает тебя на корабль.

## Как работает

- Нажимаешь кнопку (по умолчанию **F4**).
- Мод ищет на корабле обычный (не инверсный) телепорт. **Если телепорта нет — ничего не происходит.**
- Радар монитора переключается на тебя, и телепорт «нажимает» свою кнопку — тебя забирает на корабль, как если бы кто-то нажал кнопку телепорта вручную.
- Если телепорт на перезарядке — появится подсказка на экране.
- Предметы из рук при телепортации **не выпадают** (работает и для обычного, и для инверсного телепорта). Отключается опцией `KeepItemsOnTeleport` в конфиге.
- Перезарядка инверсного телепорта уменьшена с 210 до **10 секунд** (настройка `InverseTeleportCooldownSeconds`).

Важно: в мультиплеере сохранение предметов гарантированно работает, только если мод стоит у всех игроков (для телепорта на корабль достаточно мода у тебя).

## Настройка

После первого запуска игры с модом появится конфиг:

`BepInEx/config/dp991.ShipTeleportKey.cfg`

Там можно поменять кнопку (`TeleportKey`), например `T`, `F9`, `X` и т.д.
(значения — имена клавиш из Unity InputSystem `Key`).

## Сборка

Нужен .NET SDK. Путь к игре задаётся в `ShipTeleportKey.csproj` (свойство `GameDir`).

```powershell
dotnet build -c Release
```

Собранная `ShipTeleportKey.dll` автоматически копируется в `BepInEx/plugins` игры.
